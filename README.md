# Spherical Snake

*This is a fork of the [original Spherical Snake](https://github.com/kevinAlbs/SphericalSnake) by Kevin Albertson.*

Snake game on a sphere with multiple power-ups!

## Play

Play here: [GitHub Pages URL will be available after setup]

## Game Rules

- **Blue orbs** (2): Worth 1 length each, respawn when collected
- **Green orb** (1): Worth 5 length, respawns when collected
- **Red orb** (1): Instant death! Moves to a new location every 3rd orb you collect

## Hosting on GitHub Pages

To host this game on GitHub Pages from this repository:

1. Go to your repository Settings
2. Navigate to the "Pages" section in the left sidebar
3. Under "Source", select the branch you want to deploy (typically `main` or `master`)
4. Select the root folder `/` as the source
5. Click "Save"
6. Your site will be published at `https://<username>.github.io/<repository-name>/`

The game will be live at your GitHub Pages URL within a few minutes.
